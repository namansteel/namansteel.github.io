# namansteel.com

Website for **Naman Steel**, iron & steel distributor and retailer, Lakadganj, Nagpur.
Plain HTML/CSS/JS hosted on GitHub Pages. There's no build step: edit the files and push.

- `index.html`: home
- `products.html`: products overview, linking to the four product pages (`tmt-bars-nagpur.html`, `structural-steel-nagpur.html`, `ms-plates-sheets-nagpur.html`, `ms-pipes-wire-nagpur.html`)
- `tmt-weight-calculator.html`: TMT weight calculator & chart (`js/calculator.js`)
- `contact.html`: phone, hours, map, directions
- `store.html`: redirect from the old URL to `contact.html`
- `css/style.css`: all styles
- `img/products/*.svg`: product illustrations
